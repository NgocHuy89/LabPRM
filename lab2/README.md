# Flutter Application 1

A Flutter demo application with a counter increment feature.

## Getting Started

This project is a basic Flutter application that demonstrates:

- State management with `StatefulWidget`
- Material Design UI components
- Floating Action Button interaction

### How to Run

```bash
flutter run
```

## Project Structure

- `lib/main.dart`: Main application file with the MyApp widget and counter logic
- `test/widget_test.dart`: Widget tests for the application

## Features

- Counter display
- Increment button to increase the counter
- Material Design UI

## Requirements

- Flutter SDK
- Dart SDK

For more help, see the [Flutter documentation](https://flutter.dev/docs).
